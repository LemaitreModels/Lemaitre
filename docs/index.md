# LemaîtreModels

Towards parametric models of binary-black-hole spacetimes.

The animation above is only an <em>AI's impression</em> of a parametric binary-black-hole (BBH) spacetime.\
We cannot yet build accurate and efficient parametric BBH models. We only have approximate semi-analytic solutions and individual numerical simulations.
LemaîtreModels aims to connect these into a unified model, enabling new ways to study the <em class="lm-blue">fundamental physics</em> of black holes and their <em class="lm-blue">observations</em> in gravitational waves (GWs).
Below is an overview of what we can already do.
